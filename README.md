# Sped Up Hoppers Minecraft Plugin

Sped Up Hoppers is a Minecraft plugin for Paper servers that speeds up hopper transfers by clearing a hopper’s transfer cooldown after it initiates a successful inventory move.

## Install

1. Build the project with Java 21 and Maven by running `mvn package`.
2. Copy `target/plugin.jar` into your Paper server’s `plugins` folder.
3. Start or restart the server.

## Use

1. Place hoppers as usual.
2. When a hopper initiates an inventory transfer, the plugin sets its transfer cooldown to zero after the move.
3. No commands or configuration are required.
